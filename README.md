## Overview

AI Health Prediction provides a web interface for reviewing health inputs and calculating the estimated likelihood of selected diseases. Its analysis can combine symptoms with age, medical background, and lifestyle information, using trained machine-learning models to produce a prediction.

The application is also intended as an example of using artificial intelligence with healthcare-related data and early prediction tasks. Since it runs in a browser, users can access it without installing a dedicated desktop application.
